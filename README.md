# Actividad Git

Página web básica en HTML que muestra el mensaje **Hello, World!** en el navegador.

## Contenido

- `index.html`: estructura de la página, con codificación UTF-8 y configuración del área de visualización para dispositivos móviles.
- `README.md`: descripción e instrucciones de uso del proyecto.

## Cómo visualizar la página

1. Descarga o clona este repositorio.
2. Abre `index.html` con tu navegador web.

No requiere instalar dependencias ni ejecutar un servidor.

## Cómo modificarla

Abre `index.html` en un editor de texto y cambia el contenido de la etiqueta `<h1>` para personalizar el mensaje. Guarda el archivo y recarga la página en el navegador para ver los cambios.

## Tecnologías

HTML5, sin CSS ni JavaScript.
